AURA GIP  —  Plugin para Autodesk Navisworks (Manage / Simulate 2024-2026)
================================================================================

  INSTALAR EN 3 PASOS
  --------------------------------------------------------------------------
   1.  Cierra Navisworks (si esta abierto).
   2.  Doble clic en   "Instalar Aura GIP.bat"
       (te va a pedir permiso de Administrador: acepta).
   3.  Abre Navisworks  ->  pestania "Aura GIP".  Listo.

  Nota: si lo bajaste con el navegador y aparece "descarga sospechosa",
  elige "Conservar". El archivo es seguro; el aviso es porque el ZIP trae
  scripts de instalacion.

--------------------------------------------------------------------------------

  QUE HACE
   Trae a Navisworks los datos editados en la plataforma Aura GIP y los escribe
   como propiedades (pestania "Aura GIP") en los elementos del modelo, por TAG.
   Tambien permite "Publicar a la nube" el modelo con un clic.

  REQUISITOS
   - Navisworks Manage o Simulate (el visor gratis "Freedom" NO sirve: sin API).

  USO
   1. Abre tu modelo.
   2. Pestania "Aura GIP" -> "Asignar Propiedades".
   3. Marca las planillas a sincronizar -> Sincronizar.
   4. Guarda el archivo (.nwf / .nwd) para conservar las propiedades.

  CONTENIDO DEL ZIP
   - "Instalar Aura GIP.bat"  ->  lo unico que necesitas ejecutar.
   - recursos\                ->  archivos del instalador (no tocar).

  No hay nada que configurar: la URL y el token ya vienen incluidos.
